# Исходные данные

Здесь уже лежат три файла из выданного пакета:

* `LIMS.xlsx`            — лабораторные анализы (ЛИМСы…xlsx)
* `PAK.xlsx`             — выгрузка поточных анализаторов
* `tags_reference.xlsx`  — справочник тегов (листы КИП, ЛА, ПАК, ВАК)

Не хватает только двух больших телеметрий (340 МБ) — они не помещаются в архив
решения. Положите `data_1.rar` в корень проекта и выполните:

```bash
make data && make fit
```

Команда распакует `242000_tags.csv` и `avt_tags.csv` сюда и соберёт витрину.
Если архива нет, распакуйте два CSV в эту папку вручную.
